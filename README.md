# Volt Ampere-Meter
VA Meter (Volt-Ampere Meter) is an Arduino Nano-based electrical measuring device designed to measure voltage and current in an electrical load. It uses a ZMPT101B voltage sensor and an ACS current sensor to measure electrical parameters and display the measurement results in real time on an OLED display.

Main components: Arduino Nano, ZMPT101B Voltage Sensor, ACS Current Sensor, and OLED Display.
